# Landing Page - Drillo Barber

Landing page estatica pronta para GitHub Pages.

## Publicacao

O workflow `.github/workflows/pages.yml` publica automaticamente o conteudo da pasta `landpage`.

Antes de publicar, substitua nos arquivos `index.html`, `robots.txt` e `sitemap.xml`:

```text
https://seu-usuario.github.io/DrilloBarber/landpage/
```

pela URL final da pagina.
