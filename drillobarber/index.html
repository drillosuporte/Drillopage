Dúvidas frequentes

Respostas diretas, sem enrolação

O Drillo Barber funciona sem internet?

Sim. O app funciona 100% offline, salvando todos os dados no próprio dispositivo Android. Sem sinal, sem wi-fi, sem problema.

O app controla comissão dos barbeiros?

Sim. Você define uma comissão padrão por barbeiro e pode sobrescrever com uma comissão específica por serviço — tudo calculado automaticamente no fechamento do dia.

É realmente gratuito? Tem pegadinha?

O plano gratuito é permanente, não é trial. Ele tem limites de uso (30 clientes, 50 vendas/mês, 1 barbeiro). Para crescer além disso, haverá um plano Pro pago — mas a decisão é sua, na hora que fizer sentido.

Meus dados ficam seguros?

Sim. Os dados ficam salvos localmente no seu dispositivo. Nenhuma informação é enviada para servidores externos no plano atual.

Funciona em qualquer celular Android?

O app foi desenvolvido para Android e funciona em dispositivos com Android 8.0 ou superior. Não exige hardware de ponta.
